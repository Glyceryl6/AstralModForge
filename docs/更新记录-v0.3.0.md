# Astral Mod Forge v0.3.0 · 更新记录

- **修复**：`BuildLogService` 注册为项目服务，修复 Rider 工具窗口创建时的 `NullPointerException`；缺失服务时使用按项目隔离的备用实例。
- **依赖**：导出时自动剔除没有被实际调用的 `Framework/` 文件；必需的辅助类仍予保留并记录清单。
- **配置**：新增“将默认设置内嵌到 DLL”选项（默认关闭）。布尔功能开关固定开启，部分数字／字符串默认配置可被安全内联；新 MOD 不写 `.cfg` 或默认语言 JSON。
- **安全**：配置默认值不是字面量、设置被写入／传递、残留已知文件持久化 API 时拒绝导出；不会删除已有用户配置。
- **本地化**：独立语言服务支持 `CurrentLocale` 属性映射；内嵌配置模式仅使用 DLL 中的资源。
- **验证**：Java 核心专项测试 69 项，含配置模式的模拟编译部署测试；真实 Rider SDK、.NET 编译及游戏内加载仍需本机验证。
- **版本**：仅 Java 工具升级到 0.3.0，不涉及 AstralProbe / SDK / ContentPreview 版本。
