# 星航 MOD 工坊 v0.1.0 · 使用手册 / User guide

## 前提 / Requirements

- JetBrains Rider 2025.2+（目标 SDK 为 2025.2.3；更新版本需 Plugin Verifier 验证）
- Java 21，Gradle 9+，使用 `gradle buildPlugin` 发布正式插件 ZIP
- 游戏 MOD 编译：.NET 6 SDK 或支持 `net6.0` 的合适 SDK；能够访问 NuGet 源并还原 BepInEx / SNWCreations 包
- 游戏：已安装兼容的 BepInEx Unity IL2CPP；BepInEx 文件夹必须存在

## 创建新项目

1. Rider 菜单 **Tools → 星航 MOD 工坊 → 新建空 MOD**。
2. 输入符合 `lowercase.reverse.domain` 风格的 ID，例如 `dev.example.hello`。只需此项。
3. 打开生成的 `AstralModForge/Projects/dev_example_hello/dev_example_hello.csproj`。
4. 修改 `Features/SampleFeature.cs`，在 `Plugin.Load()` 中注册游戏所需的事件、服务或 IL2CPP 行为组件。
5. 运行 `dotnet restore && dotnet build -c Release`。将生成的 MOD DLL 放到游戏 `BepInEx/plugins` 下，启动游戏检查 BepInEx 日志。

## 导出现有类

1. 在 Rider 项目树选择一个或几个 `.cs` 文件（导出时也能在列表中多选）。
2. 菜单 **Tools → 星航 MOD 工坊 → 导出选中类**。
3. 输入新的 BepInEx GUID（MOD ID），检查选中的类文件。
4. 可选填写初始化和 Update 方法，多个入口以英文 `;` 分隔。例如：
   - Load: `AstralProbe.Features.Example.FeatureA::Initialize;AstralProbe.Features.Example.FeatureB::Install`
   - Update: `AstralProbe.Features.Example.FeatureA::Tick`
5. 选择默认的“内嵌 JSON”或固定语言硬编码；单独设置 `zh_cn` / `en_us`。
6. 使用 **检查依赖** 按钮预览闭包、动态本地化键、原宿主引用和自动入口。
7. 需要复制到游戏时勾选“编译完成后复制”，填写游戏根目录。未勾选则只在项目的导出文件夹中保存成果。
8. 点击导出。查看 `export-report.md` 和必要时的 `build.log`，再进行实际游戏验证。

## 不同 MOD 的本地化与配置

- BepInEx 会给 GUID 对应的插件生成自己的 `.cfg`；本工具生成的语言选择项位于 `[Language] Locale = zh_cn/en_us`。
- 语言资源不是存储在 JAR 中，而是通过 `<EmbeddedResource>` 随 `.NET DLL` 一并编译，运行时使用 `GetManifestResourceStream()` 读取。
- 首次运行会把语言默认值写入 `BepInEx/config/<MOD ID>/lang/zh_cn.json` 和 `en_us.json`；后续可编辑并每隔约 3 秒重新读取。
- 编辑已有 JSON 后，程序保留用户修改，只补充新增的词条，解析错误时保留上次的词典。
- 每个 MOD 用独立的目录与字典；转换支持源 `ModLanguageService.Translate("literal")`、`ModLocalization.T("literal")` 这类明确调用。改名不应影响原工程。
- 直接传给原版设置 UI 的裸键可能并非翻译调用。固定文本模式会要求先人工确认并改造为明确 `Translate/T` 调用；内嵌模式会发出警告。

## 导出失败时

- **没有 Init/Tick**：请提供明确入口，或先将选中类封装成小模块。不能复制一个从未有人调用的类就期望功能自动运行。
- **缺失 C# 类型**：查看 `build.log` 的 CS0246/CS0103 等；工具只负责可见同工程类型闭包，不推断游戏热更新运行期元数据。
- **依赖原版 Plugin 私有成员**：手动拆解为独立配置/服务接口，或重新编写插件 Host 部分。工具不会默默沿用 AstralProbe 的全局状态。
- **项目引用外部 SDK**：将其做成标准 NuGet 依赖或携带适当的依赖 DLL；避免安装与游戏其他 MOD 冲突的 DLL。
- **游戏目录无效**：构建仍可完成，但不会执行复制。请确认选择游戏根目录，不是 BepInEx/plugins 子目录。

## 测试范围

本包在离线 Java 21 环境中通过 29 项核心回归测试；JetBrains SDK、.NET SDK、真实游戏运行环境当前均不可用，因此附带的是试装候选而非经过 Rider 商用验证的正式版。
