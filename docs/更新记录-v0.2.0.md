# Astral Mod Forge v0.2.0 · 更新记录

- **导出**：默认将能确定为布尔值的 MOD 功能开关设置为开启；剥离原设置 UI 与配置宿主依赖。遇到不能安全转换的引用时明确拒绝导出。
- **导出**：新增“是否导出 C# 源码”选项，默认关闭；只输出编译 DLL、报告与日志。源码模式强制放在原工程之外，避免重复类定义。
- **依赖**：改为可展开的复选框树；勾选自动补充依赖，取消依赖反向撤销其上游已选功能；修正同名私有嵌套类型误判。
- **界面**：菜单、按钮、设置选项与工具窗口标题分别提供中文、英文资源；新增深浅色 SVG 工具窗口图标。
- **构建**：工具窗口可实时查看 `dotnet build` 输出、复制和清除日志；支持后台取消、构建失败阻止游戏目录部署。
- **工程**：Java 项目版本升至 `0.2.0`，提供 GitHub Actions 构建示例、49 项核心回归测试、独立示例工程及更新文档。

本工具与 AstralProbe 本体版本相互独立；本次不修改 MOD、SDK 或附属包。
