# 静态方法裁剪示例：UniversalTargetMarksService

本示例使用 AstralProbe v0.47.0 源码，选择：

`Features/Communication/Marks/UniversalTargetMarksService.cs`

## 裁剪前的依赖链

```text
UniversalTargetMarksService
  -> NativeActionButton.StretchNativeArtwork
  -> NativeActionButton.Create / CreatePlain（同一类中但本功能未调用）
       -> StableNativeAction.Prepare
            -> NativeMailActionButton.DetachSizeGears
                 -> ModSettingsLayout.ActionButtonFontSize
```

类级依赖扫描会看到同一文件中的所有成员，因此原先可能把 `ModSettingsLayout` 判定为必需依赖。

## v0.5.0 导出结果

- 保留 `NativeActionButton.StretchNativeArtwork()`。
- 移除本次功能不可达的 `Create`、`CreatePlain` 等方法。
- 移除未被调用的私有嵌套类型 `NativeColor`。
- `StableNativeAction.Prepare()` 不再可达，因此不再带入 `StableNativeAction` 和 `NativeMailActionButton`。
- `UniversalTargetMarksService` 中只读的 `ModSettingsLayout.HomeTextColor` 使用原设置声明的默认值 `16761384u`，不再依赖 `Framework.Settings.ModSettingsLayout`。
- 输出源码不包含 `Framework/Settings` 目录，也不包含 `NativeMailActionButton.cs`、`StableNativeAction.cs`。

## 安全边界

裁剪器只对可解析的顶层静态辅助类执行方法裁剪。若类包含静态字段或状态初始化、静态构造函数、属性、事件、反射、动态调用、特殊保留属性，或调用关系无法确定，则保留整个类。非静态辅助类仍按文件级依赖保留。最终 DLL 仍需使用目标 .NET SDK 编译并在游戏内验证。
