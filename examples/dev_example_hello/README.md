# dev.example.hello

生成的 BepInEx Unity IL2CPP 独立 MOD 项目。使用 Rider 打开 `dev_example_hello.csproj`，先在 ForgePaths.props 配置游戏的 BepInEx/interop 路径，再执行 `dotnet restore --configfile NuGet.Config` 和 `dotnet build -c Release --no-restore`。

Generated standalone BepInEx IL2CPP project. Build with .NET 6 SDK.

**请核对游戏运行的 BepInEx / SNWCreations 包版本，并避免加载与原 MOD 重复的功能。**
